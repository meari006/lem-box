# LEM BOX · IMAGE LAB

**一个在浏览器本地运行的图像转换工具，在报纸字符网点与 CRT 荧光点阵之间切换。**

无需上传图片，也不依赖服务端处理。打开网页、选择图片，就能生成具有两种截然不同视觉风格的图像。

**在线体验：** https://meari006.github.io/lumen-halftone/

## 两种输出风格

### HALFTONE · Newspaper Print

把图像转换成由文字组成的黑白网点画，灵感来自报纸印刷、复古漫画和传统网屏。

- 默认使用**灰色背景 + 黑色文字**，呈现中性灰阶的报纸印刷效果。
- 也可以切换为黑底白字。
- 可输入自定义文字，例如 `LEM BOX`、`LUM3N` 或 `DEAD VALLEY`。
- 界面采用灰色纸面、黑色文字和深灰控件，与 CRT 模式明显区分。

### CRT · Phosphor Display

使用荧光圆点、柔和辉光和扫描线模拟老式 CRT 显像管。

- 提供荧光绿、琥珀色、冰蓝、冷白、红色、紫色和自定义颜色。
- 自动生成与荧光颜色匹配的暗色屏幕背景。
- CRT 预览支持标准和高清质量；PNG 导出始终使用完整网格。
- 界面采用深色终端背景与荧光绿元素。

## 功能

- 支持 JPG、PNG、WebP 等常见图片格式。
- 支持点击选择图片或拖放图片。
- 三种网点算法：
  - **Floyd–Steinberg**：误差扩散，保留更多细节和层次。
  - **Bayer**：有序网点，形成规则的几何颗粒。
  - **Random**：随机分布，带来更明显的颗粒感。
- 网格高度支持 360、720、1080、1440 行预设，以及 64–2400 行自定义设置。
- 可调整整体浓度、对比度和 PNG 输出单元大小。
- 支持明暗反转。
- 支持导出 TXT 矩阵和 PNG 图像。
- 提供中文 / English 界面。

## 使用方法

1. 打开 [LEM BOX](https://meari006.github.io/lumen-halftone/)。
2. 选择或拖入一张图片。
3. 在输出模式中选择 **HALFTONE** 或 **CRT**。
4. 根据模式调整文字、荧光颜色、网点算法和网格高度。
5. 点击生成，检查预览效果。
6. 导出 TXT 或 PNG。

建议先用 360 行快速确认效果，再提高网格高度。更大的网格会消耗更多内存和处理时间。

## 隐私与处理方式

所有图像处理都在浏览器本地完成，图片不会上传到服务器。选择的图片只在当前页面中用于生成预览和导出结果。

## 项目结构

项目以轻量级静态网页形式运行，核心界面、样式和图像处理逻辑位于 `index.html`，可直接通过 GitHub Pages 发布。

## GitHub Pages

如需在自己的仓库部署：

1. 打开仓库 **Settings → Pages**。
2. 选择 **Deploy from a branch**。
3. 选择 `main` 分支和 `/(root)` 目录。
4. 保存后等待 GitHub Pages 完成部署。
