# LEM BOX · IMAGE LAB

**LEM BOX 是一个在浏览器本地运行的图像转换工具。** 它可以把图片转换成报纸字符、印刷圆点或 CRT 荧光点阵。无需安装软件，也不需要把图片上传到服务器。

- **在线使用：** https://meari006.github.io/lumen-halftone/
- **当前版本：** v0.12.0
- **运行方式：** 静态网页，使用浏览器打开即可

---

## 三种图像模式

### GLYPH · Newspaper Glyphs

把图像转换成由字符组成的黑白网点画，模拟报纸印刷和字符画效果。

**像素分组**

每个字符可以代表不同大小的正方形像素区域：

| 设置 | 区域大小 | 每个字符代表 |
|---|---:|---:|
| 1×1 | 1 × 1 | 1 个像素 |
| 2×2 | 2 × 2 | 4 个像素 |
| 4×4 | 4 × 4 | 16 个像素 |
| 6×6 | 6 × 6 | 36 个像素 |
| 8×8 | 8 × 8 | 64 个像素 |

- **像素文字（Pixel text）：** 自定义字符集，例如 `LUM3N`。建议按从浅到深的视觉浓度排列字符。
- **1×1 模式：** 保留逐像素循环字符的原始方式。
- **分组模式：** 每个方块统计其中被点亮的像素比例，再按覆盖率从字符集中选择字符。覆盖率越高，使用的字符越靠后。
- **不完整边缘：** 图片尺寸不能被方块边长整除时，边缘区域只统计实际存在的像素，不补边、不裁切。
- **配色：** 白底黑字或黑底白字。

例如，6×6 模式下，一个字符对应最多 36 个基础像素；若处在图像边缘，实际区域可能小于 36 个像素，算法会按该区域的真实像素总数计算覆盖率。

### DOT · Printed Ink Dots

把图像转换成规则排列的实心圆点，模拟纸面油墨印刷。

- 使用实心圆点，不加入 CRT 荧光辉光或扫描线。
- 支持白底黑点和黑底浅色点。
- 预览与 PNG 导出使用同一张基础点阵。

### CRT · Phosphor Display

使用荧光点、柔和辉光和扫描线，模拟老式 CRT 显像管。

- 荧光颜色：绿色、琥珀色、冰蓝、冷白、红色、紫色和自定义颜色。
- 自定义荧光色会自动搭配暗色屏幕背景。
- 预览提供标准和高清质量选项。
- PNG 导出使用完整基础网格，不受预览质量选项影响。

## 图像处理选项

**网点算法**

- **Floyd–Steinberg：** 误差扩散，适合保留连续明暗层次和图像细节。
- **Bayer：** 有序抖动，形成规则、重复的网点结构。
- **Random：** 随机抖动，形成更明显的颗粒分布。

**其他设置**

- 网格高度预设：360、720、1080、1440 行。
- 自定义网格高度：64–2400 行。
- 调整整体浓度和对比度。
- 反转明暗。
- GLYPH 模式可调整像素文字、字符分组尺寸和纸面配色。
- CRT 模式可调整荧光颜色与预览质量。
- PNG 导出可调整字符大小或点阵单元大小。

## 使用方法

1. 打开 [LEM BOX 在线页面](https://meari006.github.io/lumen-halftone/)。
2. 选择图片，或把图片拖入上传区域。支持 JPG、PNG、WebP 等常见格式。
3. 在顶部选择 **GLYPH**、**DOT** 或 **CRT**。
4. 调整网格高度、网点算法、浓度和对比度等参数。
5. 在 GLYPH 模式中，选择每个字符代表的像素区域大小，并设置像素文字。
6. 点击生成，查看预览。
7. 根据需要导出 TXT 或 PNG。

建议先用 360 行测试构图和参数，再提高网格高度进行正式导出。高分辨率网格和较大的 PNG 单元尺寸会增加处理时间与内存占用。

---

## 导出说明

- **TXT：** 导出字符矩阵或点阵文本，可用于终端、文本编辑器或进一步处理。
- **PNG：** 导出图像文件。GLYPH 的 PNG 尺寸会根据分组后的字符网格计算；DOT 和 CRT 使用基础像素网格。
- **预览与导出：** GLYPH 的分组覆盖率由同一套字符映射逻辑计算，预览、TXT 和 PNG 使用一致的分组结果。预览可能为了显示性能降低采样密度，导出则使用完整网格。

## 隐私与本地处理

图像解码、网格计算、预览和导出均在浏览器本地完成。项目本身不会把用户选择的图片上传到服务器，也不需要账号登录。

---

## 项目结构

项目采用轻量级静态网页结构，核心文件如下：

- `index.html`：页面结构、样式、交互逻辑和图像处理算法。
- `README.md`：项目说明。

无需构建工具或后端服务。

---

## 部署到 GitHub Pages

1. 将项目文件放入 GitHub 仓库。
2. 进入仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择 `main` 分支和 `/(root)` 目录。
5. 保存设置，等待 GitHub Pages 发布。
