# LUM3N · HALFTONE

**把照片变成复古报纸与黑白漫画风格的文字网点印刷画。**

HALFTONE 的灵感来自老式报纸印刷、漫画网点和复古黑白印刷品。它不追求普通照片滤镜那种平滑过渡，而是把画面拆解成一格格网点，再用自定义字符填充，让文字本身成为画面里的“油墨颗粒”。

## 效果方向

- **报纸印刷**：黑白、高反差、颗粒感，像经过扫描的旧报纸照片。
- **漫画网点**：通过网点疏密表现阴影、轮廓和明暗层次。
- **文字印刷**：用自定义字符替代圆点，例如 `LUM3N`、`DEAD VALLEY`，让图像带有独特的文字纹理。
- **复古质感**：适合黑白肖像、建筑、街景和具有明确明暗对比的图片。

## 使用

1. 打开网页并选择一张图片。
2. 输入想要用于填充网点的文字。
3. 选择网点算法、网格高度和明暗参数。
4. 点击“生成文字网点图”。
5. 导出 TXT 字符矩阵或 PNG 印刷效果图。

## 网点算法

- **Floyd–Steinberg**：误差扩散，细节和灰阶过渡更丰富。
- **Bayer**：规则有序网点，更接近传统印刷网屏的几何感。
- **随机网点**：颗粒分布更自然，带有粗粝的纸面质感。

## 输出与隐私

- 默认 1080 行，宽度按原图比例计算。
- TXT 保存逐格字符矩阵；PNG 保存绘制后的视觉图像。
- 所有图像处理都在浏览器本地完成，图片不会上传到服务器。
